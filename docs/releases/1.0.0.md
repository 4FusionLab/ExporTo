## English

ExporTo 1.0.0 sends selected Fusion geometry to locally installed slicers and CAD applications on macOS and Windows. It is distributed under the PolyForm Noncommercial License 1.0.0.

- Use **Export to** for STEP and **Export to → STL** for a mesh. STL also supports individual solid bodies.
- Installed destinations appear automatically. ExporTo displays their original icons when available.
- **Clear cache** shows the size of temporary exports and removes them on demand.

To install, extract the release ZIP to a permanent folder. In Fusion, open **Utilities → Scripts and Add-Ins → Add-Ins**, select **+ → Script or add-in from device**, and choose the extracted ExporTo folder. Select **Run** and enable **Run on Startup**.

## Русский

ExporTo 1.0.0 отправляет выбранную геометрию из Fusion в установленные слайсеры и CAD-программы на macOS и Windows. Аддин распространяется по лицензии PolyForm Noncommercial 1.0.0.

- Выберите **Export to** для STEP или **Export to → STL** для сетки. STL также поддерживает отдельные твёрдые тела.
- Установленные программы появляются автоматически. ExporTo показывает их оригинальные иконки, когда они доступны.
- **Clear cache** показывает размер временных файлов и удаляет их по нажатию.

Распакуйте ZIP релиза в постоянную папку. В Fusion откройте **Utilities → Scripts and Add-Ins → Add-Ins**, нажмите **+ → Script or add-in from device** и выберите распакованную папку ExporTo. Нажмите **Run** и включите **Run on Startup**.
